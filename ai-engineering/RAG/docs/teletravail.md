Charte du télétravail MEDZA
Le télétravail est autorisé jusqu'à 3 jours par semaine après la période d'essai.
Le mardi est un jour de présence obligatoire au bureau pour toute l'équipe.
Une indemnité de 20 euros par mois est versée pour couvrir les frais d'internet.
Le matériel (écran, clavier) est fourni par l'entreprise sur demande.
